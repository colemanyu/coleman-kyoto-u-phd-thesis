\section{Experiments} \label{sec:experiments}

% exchange rate does not depend on time covariates

This section presents experiments demonstrating the effectiveness of using nearest neighbor information to improve GBRT performance on the time series forecasting task.

The experiments are conducted on a personal laptop equipped with an Apple M1 Pro chip and 16 GB of memory, using Python for implementation.
We employ \texttt{stumpy} for the matrix profile implementation and \texttt{xgboost} for the XGBoost implementation.
The code and data are available at \url{https://github.com/colemanyu/matrix-profile-motif-forecasting}.

The evaluation is conducted on four datasets, as listed in Table~\ref{tab:dataset_statistics}.
Three evaluation metrics are used, namely RMSE, MAE, and WAPE.
There are two scenarios for the datasets' use case.
\begin{itemize}
  \item Without known input time-covariates $\textbf{u}_i$ (i.e. $M_u = 0$): The models rely solely on the target values.
  \item With known input time-covariates $\textbf{u}_i$ (i.e. $M_u> 0 $): The models incorporate additional time-derived known input covariates $u_i$,  as listed in Table~\ref{tab:known_covariates}
\end{itemize}

\subsection{Effect of the length l of the immediate subsequence}

The effect of the length $l$ of the immediate subsequence is investigated.
We tested for five different lengths $l \in 1, 2, \ceil{h/4}, \ceil{h/2}, h$.
For \texttt{Exchange-Rate} with $h = 9$, $l \in \{1, 2, 6, 12, 24\}$.
For other datasets with $h = 24$, $l \in \{1, 2, 3, 5, 9\}$.
\input{../figures/points_trend_analysis_RMSE}
\input{../figures/points_trend_analysis_MAE}
The results are plotted in Figures~\ref{fig:points_trend_analysis_RMSE},~\ref{fig:points_trend_analysis_MAE}.
Since the WAPE plot is similar to the MAE plot, only the RMSE and WAPE plots are shown here.

For \texttt{Electricity} and \texttt{PeMSD7}, the performance improves for all the metrics as $l$ increases.
For \texttt{Traffic}, the performance of \textsf{GBRT-NN-S} on RMSE improves as $l$ increases. In contrast, the performance of \textsf{GBRT-NN} on RMSE decays as $l$ increases. 
But for MAE, both models improve as $l$ increases.
For \texttt{Exchange-Rate}, both models achieve the best result when $l = 6$ for all the metrics.

\subsection{Comparison between the two scenarios}

For \texttt{Electricity} and \texttt{PeMSD7}, the models perform better when time-covariates are incorporated.
For \texttt{Traffic}, incorporating the covariates worsens the results.
For \texttt{Exchange-Rate}, the performances of the models are similar between the two scenarios. This indicates that this dataset is less dependent on time.

\subsection{Effect of using z-normalized instead of raw values}

In this part, we study the effect of using z-normalized target values of the immediate subsequences.
By default, we use the target values directly as the features.
We have tested using the z-normalized representation of the target values instead of the raw values in all the previous experiments.
In detail, for each dataset, there are two scenarios, and the two models have been tested five times for five different $l$. It results in 20 combinations in the experimental setting. 
\input{../figures/original_vs_normalize}
The percentage change of using the z-normalized representation instead is shown in Figure~\ref{fig:original_vs_normalize}
It shows that using the raw values of the immediate subsequence is preferable.

\subsection{Effect of using pairwise difference representation instead of raw values}

In this part, we study the effect of using pairwise differences, which captures the trend, as the features.
We have tested using the pairwise difference representation of the target values instead of the raw values in all the previous experiments.
For a given time series $T=t_1, t_2, \dots, t_n$, its pairwise differences representation $T'$ refers to $T' = t_2-t_1, t_3-t_2, \dots, t_n-t_{n-1}$.
To note, the first entry is computed by subtracting the first entry of the immediate subsequence from the last entry of the nearest neighbor.
Hence, the length of the pairwise difference representation is the same as the original one.
In detail, for each dataset, there are two scenarios, and the two models have been tested five times for five different $l$. It results in 20 combinations in the experimental setting. 
Same as the previous part, it has been tested for 20 combinations for using the pairwise difference representation instead.
\input{../figures/raw_vs_pairwise}
The result is plotted on Figure~\ref{fig:raw_vs_pairwise}.
It shows that using the raw values of the immediate subsequence is preferable.

\subsection{Summary of the experiments on the two primary models}
Based on the above experiments, we present the following summary for the downstream analysis.
\begin{enumerate}
  \item \textbf{Variable Impact of Covariates}: The inclusion of time-covariates does not always help. It depends on the dataset.
  \item \textbf{Lag Selection}: We set $l = 6$ for \texttt{Exchange-Rate} and $l = h$ for other datasets. 
  \item \textbf{Data Representation}: Using raw values for the immediate subsequences. We argue that it is because raw values preserve original information.
  \item Across 12 evaluation combinations (four datasets with three metrics), \textsf{GBRT-NN-S} demonstrated improvement in 9 cases, remained consistent in 2, and showed a performance decline in only 1 when incorporating time-covariates, while showing improvement in 10 cases, and remained consistent in 2 for not incorporating known input covariates. 
  \item \textsf{GBRT-NN-S} performs much better than \textsf{GBRT-NN} in \texttt{Traffic} and performs similarly on the other datasets in both scenarios.
  \item \texttt{Exchange-Rate} only has a mild improvement on our models. It indicates that this dataset is not strongly dependent on historically similar occurrences.
\end{enumerate}

\subsection{Incorporating the target values of the nearest neighbor}

% Discuss more complex methods NN+ and NN++
We have further incorporated the target values (either only the last point or all of them) of the nearest neighbor. 
The results are in Tables~\ref{tab:results_without_covariates}, \ref{tab:results_with_covariates}.
By incorporating these features, the models improve on \texttt{Traffic} and \texttt{PeMSD07}.
\textsf{GBRT-NNC\textsuperscript{++}-S} performs the best for both the scenarios.

For \texttt{Electricity}, \textsf{GBRT-NNC\textsuperscript{++}-S} achieves the best and the second best on WAPE in the two scenarios, respectively.
It worsens RMSE for the case without known input-time covariates compared to the baseline while still improve RMSE for the case with known input-time covariates.
It indicates that in the absence of time covariates, \textsf{GBRT-NNC\textsuperscript{++}-S} makes wrong predictions for some outliers.

In general, these models improve average prediction performance but cannot handle certain outlier cases.

As mentioned above, \texttt{Exchange-Rate} is insensitive to long-range history. It can also be noted by the small best $l$ in Figure~\ref{fig:points_trend_analysis_RMSE}, \ref{fig:points_trend_analysis_MAE}.
